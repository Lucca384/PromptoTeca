## 1.1 Nome da Marca

### Nome Principal: **PromptoTeca**

**Justificativa:**
- Fusão de "Prompt" + "Biblioteca" (Teca)
- Sonoridade brasileira e memorável
- Transmite ideia de coleção organizada
- Fácil de pronunciar e escrever
- Domínio provavelmente disponível
- Funciona bem em português e inglês

```
┌─────────────────────────────────────────────────────────────┐
│  SISTEMA DE PROTEÇÃO POR SENHA                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │

│  ├── Armazenamento do token: localStorage                   │
│  ├── HTTPS: Obrigatório em produção                         │
│  └── Rate limiting: 5 tentativas/minuto                     │
│                                                             │
│  📝 PÁGINA DE LOGIN                                         │
│  ├── Rota: /login                                           │
│  ├── Layout: Centralizado, minimalista                      │

│  │   ├── Logo PromptoTeca                                   │

│  7. Se válida → retorna JWT                                 │
│  8. Client salva token em localStorage                      │
│  9. Redirect para /biblioteca                               │
│  10. Requests subsequentes incluem token                    │
│                                                             │
│  ⚠️ ESTADOS DE ERRO                                         │

│  ├── Muitas tentativas: "Aguarde X segundos."               │

│  └── Sessão expirada: "Sua sessão expirou. Faça login."     │

│  ├── Limpa token do localStorage                            │
│  ├── Redirect para /login                                   │
│  └── Sem confirmação necessária                             │
│                                                             │
│  📧 RECUPERAÇÃO DE ACESSO                                   │

│  │                                                          │
│  │  ROTAS PROTEGIDAS:                                       │
```
